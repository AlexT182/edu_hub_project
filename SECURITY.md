# Security Policy

If you believe you found a security or privacy issue related to EduHub, please report it privately.

## Contact

- Email: `admin@quocanh.vn`

If needed, include "Security" in the subject line.

## Please do not disclose publicly first

Do not open a public issue or post sensitive details publicly for:

- admin access problems,
- credential exposure,
- lead or user-data exposure,
- unsafe permission behavior,
- backend/API secret leakage,
- moderation bypass details,
- any issue that could expose private data.

## What to include

Please include:

- a short summary,
- impact,
- reproduction steps,
- affected URL or product area,
- screenshots or logs with secrets redacted.

## Scope notes

Security review should consider:

- public community pages,
- login/register/auth behavior,
- admin panel access control,
- lead data handling,
- chatbot data flow,
- hosted backend/API integrations,
- notification and contact workflows.

## Disclosure handling

We prefer coordinated disclosure:

1. private report,
2. reproduction and assessment,
3. fix or mitigation,
4. user/operator communication if required.

There is currently no public bug bounty program.
