# Support

EduHub is a hosted product and is supported through direct operator contact.

## Fastest contact path

- Email: `admin@quocanh.vn`

## What to include when asking for help

Please send:

- the issue in one or two clear sentences,
- the page or flow where it happened,
- whether it affects the public community or the admin side,
- your account email if relevant,
- screenshots if the issue is visual,
- the browser/device if the issue is web or mobile specific.

## What this repo is for

This repository is for:

- product information,
- public FAQ,
- roadmap visibility,
- support routing.

This repository is not the source repository for the live product.

## Recommended support flow

### Public site issues

Use email for:

- login problems,
- broken pages,
- posting/comment issues,
- chatbot issues,
- account problems.

### Admin/operator issues

Use direct email for:

- admin access issues,
- moderation problems,
- lead workflow issues,
- chatbot history/review issues,
- settings or permissions problems.

### Product questions

Read:

- [README.md](README.md)
- [docs/FAQ.md](docs/FAQ.md)
- [docs/PRIVACY.md](docs/PRIVACY.md)

## Do not send publicly

Do not post or share in public:

- admin credentials,
- private user information,
- raw lead exports,
- screenshots containing sensitive admin data,
- API keys or backend tokens.

For anything sensitive, use email: `admin@quocanh.vn`.

## Response expectations

- Support is human-handled.
- Security- or privacy-sensitive reports should be sent privately.
