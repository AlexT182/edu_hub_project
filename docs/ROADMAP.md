# Roadmap

This is a public-facing roadmap summary, not a promise of exact delivery dates.

## Current visible product shape

- Public community feed
- Search and topic-based discovery
- Login/register flow
- AI chatbot-assisted Q&A
- Admin dashboard and management surfaces
- Lead handling workflow

## Near-term improvement areas

- Better public onboarding and education flow
- Stronger moderation and admin clarity
- Better chatbot scope control and handoff UX
- Improved topic/category organization
- More polished admin reporting and workflow visibility

## Public-roadmap principle

The roadmap should describe:

- what is already real,
- what is improving,
- what still needs caveats.

It should not imply that the source code is public or that self-hosted distribution is available.
